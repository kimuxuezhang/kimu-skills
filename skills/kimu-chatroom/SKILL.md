# Kimu 聊天室

把一个问题变成有结构的圆桌讨论。目标不是制造热闹，也不是用名人数量制造权威感，而是让真正相关、能够追溯的思想视角暴露假设、冲突和选择代价。

用户可以输入：

```text
Kimu 聊天室：{话题}
Kimu 聊天室：请用{人物或流派}讨论{话题}
Kimu 聊天室：请让合适的历史教育家讨论{教培或课程问题}
```

## 建立圆桌

先确认本轮真正要判断的问题。话题过大时，将它收窄成一个能产生分歧的问句；已有明确问句时不重复追问。

先判断话题属于哪一种：

- **教培优先**：教师成长、教学方法、课程设计、学习效果、师生关系、线下转线上或知识付费教育。
- **一般圆桌**：商业、哲学、社会、个人选择或其他不以教学为中心的问题。

教培优先话题必须读取 [历史教育家选席表](references/historical-educators.md)，再根据问题选人。一般圆桌继续使用下方的通用选择规则。

### 用户指定人物

保留用户选择。若某位人物与问题缺少可验证的思想关联，说明限制，并把其角色改写为用户真正需要的观察角度。

### 用户未指定人物

教培优先话题默认提出 3 位历史教育家。必要时增加 1 个“当代证据席位”，负责平台规则、线上学习数据、AI 能力或当前市场事实，不把现代事实强塞给历史人物。

选择历史教育家时必须同时满足：

- 已去世，或已经形成稳定、可追溯的历史评价；
- 留下著作、课程实践、学校实践或可靠记录；
- 思想与本题直接相关，而不是只因名气大；
- 与其他席位存在真实方法分歧，能够互相质询。

死亡本身不是质量证明。若一个人物只有名言流传、缺少可核验的教育思想或与问题无关，不进入候选。涉及课程商业模式时，默认仍以历史教育家为主体；确有必要可增加 1 位已故且著作可靠的管理、传播或经济思想家，并说明其不是教育家。

一般圆桌提出 3–5 个互补视角。选择依据是它们分别处理不同变量，例如：

- 激励与制度；
- 认知偏差与行为；
- 资源配置与机会成本；
- 组织执行与反馈；
- 伦理、长期影响或利益相关者。

每个候选只说明两点：它负责看什么，以及它可能反驳谁。若用户只是说「直接开始」，选择差异最大的三个视角并继续；否则让用户确认或调整。

## 角色真实性

- 人物角色只代表其公开、可核验的理论或著作，不声称是真人本人。
- 不编造引语、私生活、未公开意见或对当前事件的“本人表态”。
- 无法确认的观点写成分析者推断，不使用引号伪装成原话。
- 用户指定当代人物时可以讨论，但要避免把传播风格当成完整理论。
- 历史人物没有讨论过线上课、短视频、AI 或当前平台时，只能从其已知思想推导可能关注的原则，并明确这是迁移分析。
- 历史地位不能代替论证。主持人要指出理论产生的时代条件，以及哪些部分可能不适用于今天。

## 讨论结构

每轮围绕同一个焦点完成三段：

1. **立场**：每个角色给出判断、依据和一个最担心的变量。
2. **交叉质询**：每个角色挑选一条其他观点，指出它忽略的条件或证据。
3. **主持人收束**：把分歧改写成用户可验证的选择条件。

角色发言应彼此独立，避免所有人只是换一种语气表达同一答案。若宿主支持独立工作单元或并行 Agent，可让每个角色分别分析后再汇总；若不支持，则在同一模型中分段生成，并明确这是模拟圆桌。

## 输出格式

```markdown
## 本轮焦点
{一个可判断的问题}

### {视角一}
判断：...
依据：...
质询：...

### {视角二}
...

## 主持人结论
- 已形成的共识：...
- 真正的分歧：...
- 分歧取决于哪些事实：...
- 用户现在可采取的验证或选择：...

## 教培落点（仅教培优先话题）
- 对教师行为的影响：...
- 对课程或教学设计的影响：...
- 仍需用当代证据确认：...

状态：圆桌继续
```

不必机械展示空栏目；内容简单时可以压缩，但必须保留真实分歧和主持人结论。

## 继续与结束

圆桌开始后，普通后续问题沿用本轮角色和已形成的结论。新一轮只回应用户新增的反驳、证据或条件，不重新介绍所有人物。

以下表达结束圆桌：

- 「结束聊天室」
- 「退出圆桌」
- 「Kimu：返回工具箱」

用户要求更换角色时，保留讨论记录，只替换指定席位并说明新视角补足了什么。

## 质量检查

交付前确认：

- 每个角色处理的变量确实不同；
- 教培话题的人物选择能在选席表中找到依据，且不是名人拼盘；
- 至少存在一处有意义的相互质询；
- 事实、解释和价值判断没有混成一件事；
- 历史理论、迁移推断和当代事实已经分开；
- 主持人没有用折中话术掩盖关键冲突；
- 建议包含判断条件，而不只是泛泛行动口号。

完成一轮后停止，等待用户继续、换人或结束。

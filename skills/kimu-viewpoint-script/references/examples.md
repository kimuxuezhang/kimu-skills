## 反例：P84冗余词修改前后

修改前：

```text
【本段P84】
这一篇的核心
先有素材，再有标题与开头
再按平台决策路径
分别设计标题、封面与开头
```

问题：`这一篇的核心`、`先有`、`再按`、`分别设计`为了把句子说完整而存在；“标题与开头”重复出现，没有增加新信息。

压缩后：

```text
【本段P84】
素材提取
平台决策路径
标题 / 封面 / 开头
```

## 正例A：抽象知识压缩

```text
【本段P2】
零基础进入新平台
公开规则 → 数据观察 → 小规模测试
不从爆款技巧开始

【本段P6】
平台目标 → 奖励行为
奖励行为 → 内容设计
技巧只是推导结果

【本段P8】
算法负责放大
内容价值决定上限
大素材优先于小优化

【本段P9】
验证流程
定义问题 → 罗列假设
批量测试 → 保留有效方案

【本段P10】
一次只改一个关键变量
封面、标题、开头、发布时间
避免结果无法归因

【本段P16】
转化路径
购买前必须看懂产品
信息断点就是转化断点

【本段P19】
内容影响力四层
告知 → 引导 → 启发 → 改造
越往后，影响越深

【本段P25】
告知回答“怎么做”
引导回答“为什么要改”
后者更容易建立信任

【本段P27】
启发结构
反常识观点 → 多个案例
新概念 → 行动方案

【本段P37】
伦理边界
目的透明、方法公开
提供能力、保留选择
```

## 正例B：商业逻辑与案例压缩

```text
【本段P4】
商业账号目标
不是单纯播放量
而是可持续成交

【本段P5】
转化四要素
有效曝光 × 需求匹配
信任 × 产品承接

【本段P8】
复盘指标服从内容目标
引流看曝光与主页访问
转化看咨询与成交

【本段P9】
视频可以独立传播
账号必须整体设计
每条内容承担不同任务

【本段P15】
账号是一组牌
单条内容完成局部任务
组合后形成成交路径

【本段P22】
选题流量上限
观看需求 ÷ 内容供给
供需差越大，机会越大

【本段P28】
需求扩展
产品功能 → 用户问题
用户问题 → 公共情绪

【本段P29】
餐饮案例
“本店菜品”需求小
“顾客冲突”需求更大

【本段P31】
三类用户
立即购买
暂缓购买
潜在需求

【本段P34】
短视频是漏斗
发现 → 熟悉 → 信任
需求成熟后成交

【本段P39】
用户思维
不是“我有什么”
而是“他在意什么”
```
